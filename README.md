# 西南政法大学考博英语历年真题在线测试

一个无后端、可直接部署到 GitHub Pages / Gitee Pages 的静态网页题库。

## 功能

- 2000–2017 年中 14 套可提取完整题面的历年卷
- 2019、2022、2024 三套题型回忆版
- 保留原卷题面顺序，按原题型生成电子答题卡
- 有答案的客观题自动评分；主观题与无答案年份不虚构评分
- 作答与计时仅保存在浏览器 `localStorage`
- 响应式布局，支持手机和桌面端

## 本地预览

直接打开 `index.html`，或在目录内启动任意静态服务器：

```powershell
python -m http.server 8080
```

## 重新生成题库数据

生成脚本默认从项目上一级目录读取原始 PDF：

```powershell
python tools/build_exams.py
```

生成结果写入 `data/exams.js`。原始 PDF 不进入 Git 仓库，避免仓库体积膨胀。

## 资料边界

完整套卷来自本地 `2000-2017西南政法大学考博英语试题及解析.pdf`。2019、2022、2024 来自回忆版单页资料；缺失题干不补写。2004、2018、2019 的独立扫描版没有可靠文本层，暂不作为可评分套卷导入。
